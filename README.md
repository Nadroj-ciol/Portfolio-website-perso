## 🛠️ Stack Technique

- **Frontend** : HTML5 sémantique pur, CSS3 moderne (Variables CSS, Flexbox, CSS Grid), JavaScript ES6+ Vanilla.
- **Design System** : Thème sombre inspiré de l'esthétique Swiss Design, Vercel et Linear (zéro framework lourd, zéro dépendance inutile).
- **Responsive** : Conception Mobile-First stricte, zéro débordement horizontal, accessible et optimisé pour le tactile.
- **Hébergement & Prod** : Conçu pour déploiement instantané sur GitHub Pages ou Vercel.

## 💻 Lancer le projet en local

Aucune installation de dépendances lourdes n'est requise :

```bash
# Cloner le dépôt
git clone https://github.com/Nadroj-ciol/Portfolio-website-perso.git

# Se rendre dans le dossier
cd Portfolio-website-perso

# Lancer un serveur local léger (ex: Python 3)
python3 -m http.server 8080
```
Puis ouvrir `http://localhost:8080` dans votre navigateur.
